## 搬瓦工荷兰购买前要注意什么

### 这是自管理 VPS

官方明确说明，搬瓦工 VPS 是 self-managed，也就是自管理服务。服务器系统、网站程序、SSH 密钥、防火墙、数据库、安全更新和应用故障排查，主要由用户自己处理。

如果你希望服务商帮忙配置网站、修复程序、优化数据库，购买前要先确认支持范围。自管理 VPS 的价格通常更容易控制，但它把一部分运维工作交给了用户。

### 不要把端口带宽当成实际下载速度

套餐标注的 2.5Gbps、5Gbps 或 10Gbps，是网络端口能力。实际传输速度取决于：

- 访问者所在地
- 对端网络
- 国际路由
- 服务器负载
- 磁盘读写
- 应用程序
- 单连接或多连接方式
- 当时的拥堵程度

如果你的项目只是普通博客或企业站，1Gbps 以上的端口通常已经不是最先需要解决的问题。反而应该优先考虑内存、数据库、缓存、备份和线路稳定性。

### 检查退款和服务条款

购买前要阅读当前服务条款、资源使用政策和退款规则。官方条款会对 CPU 使用、网络资源、滥用行为和不同产品的限制作出说明，具体套餐也可能有单独规则。

不要把 VPS 当成无限制的计算资源。长时间占满 CPU、发送异常流量、运行高风险服务或触发滥用投诉，都可能导致服务受到限制。

### 购买后先做基础测试

拿到服务器后，可以按这个顺序检查：

1. 确认系统版本、磁盘容量、内存和 CPU 数量。
2. 检查 IPv4、IPv6 和反向 DNS 是否符合需求。
3. 测试目标地区的延迟和丢包。
4. 配置 SSH 密钥，关闭不必要的登录方式。
5. 设置防火墙，只开放必要端口。
6. 创建快照或备份。
7. 安装监控，观察 CPU、内存、磁盘和网络流量。
8. 再部署正式网站或业务程序。

这样做看起来有点琐碎，但比上线后才发现端口、内存或路由不合适省事得多。
